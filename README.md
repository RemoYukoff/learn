# learn: AI Engineer

Local, module-based study site for the skills that AI Engineer job descriptions ask for: LLM APIs, tool use, agent orchestration (LangGraph, LangChain, CrewAI, Microsoft Agent Framework), RAG, evals, MCP, enterprise integrations, deployment and open-source models.

Content is written in Spanish. Code examples are Python.

## Run it

```sh
./serve.sh            # http://localhost:8787
```

The page loads Markdown with `fetch()`, so opening `index.html` from `file://` does not work. Always serve it.

## How it is organized

```
index.html, app.js, styles.css   viewer (no build step, no framework)
vendor/                          marked + highlight.js, pinned
manifest.json                    module index, generated by validate.py
modules/<NN-slug>/
  module.json                    metadata (title, order, level, prereqs, tags, versions, status)
  NN-chapter.md                  one chapter per file, with frontmatter
  code/                          runnable examples + requirements.txt + .env.example
.claude/skills/add-module/       Claude Code skill that writes new modules
```

### Chapter format

Every chapter starts with frontmatter:

```md
---
title: Loop de agente desde cero
order: 3
type: concepto        # concepto | implementacion
---
```

When one idea is implemented by several technologies, the chapter first explains it without tying it to any of them, then shows a tab switcher:

```md
:::tabs
== LangGraph
...markdown...
== CrewAI
...markdown...
:::
```

The chosen tab is remembered across chapters, like language switchers in framework docs.

### Running the examples

Each module has its own `code/requirements.txt`. Use one virtual environment per module (some frameworks pin conflicting versions):

```sh
cd modules/01-tool-use/code
uv venv -p 3.12 && source .venv/bin/activate   # or .venv/bin/activate.fish
uv pip install -r requirements.txt
cp .env.example .env                            # fill in ANTHROPIC_API_KEY / OPENROUTER_API_KEY
python 01_first_tool.py
```

## Adding a module

In Claude Code, from this repo:

```
/add-module <technology or concept>
```

The skill researches current versions, writes the chapters and runnable code, validates the structure, regenerates `manifest.json`, checks the render in headless Chromium and commits.

Manual check at any time:

```sh
python3 .claude/skills/add-module/scripts/validate.py
```

# learn

Local study site made of standalone modules. Each module teaches one technology or concept: theory first, then the code that implements it.

Content is written in Spanish. It is reading material only: code appears as Python snippets inside the chapters, and nothing in the repo needs to be run, installed or configured with API keys.

## Run it

```sh
./serve.sh            # http://localhost:8787
```

The page loads Markdown with `fetch()`, so opening `index.html` from `file://` does not work. Always serve it.

## How it is organized

```
index.html, app.js, styles.css   viewer (no build step, no framework)
vendor/                          marked, highlight.js, mermaid (pinned)
manifest.json                    module index, generated by validate.py
modules/<NN-slug>/
  module.json                    metadata (title, order, level, prereqs, tags, versions)
  NN-chapter.md                  one chapter per file, with frontmatter
.claude/skills/add-module/       Claude Code skill that writes new modules
```

### Chapter format

Every chapter starts with frontmatter:

```md
---
title: Loop de agente desde cero
order: 3
type: concepto        # concepto | implementacion
---
```

When one idea is implemented by several technologies, the chapter first explains it without tying it to any of them, then shows a tab switcher:

```md
:::tabs
== LangGraph
...markdown...
== CrewAI
...markdown...
:::
```

The chosen tab is remembered across chapters, like language switchers in framework docs.

Diagrams are written as ```` ```mermaid ```` blocks (rendered with the site palette, light and dark) or as inline SVG for custom visuals. Nodes take the site classes `:::input`, `:::process`, `:::store`, `:::human`, `:::risk`.

## Adding a module

In Claude Code, from this repo:

```
/add-module <technology or concept>
```

The skill researches current library versions, checks every snippet against the installed library, writes the chapters, validates the structure, regenerates `manifest.json`, checks the render in headless Chromium and commits.

Manual check at any time:

```sh
python3 .claude/skills/add-module/scripts/validate.py
```

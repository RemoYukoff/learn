# Learn

Módulos de estudio independientes: cada uno enseña una tecnología o un concepto de punta a punta.

Cada capítulo explica primero qué hace la cosa y cómo funciona, y después muestra en código cómo se implementa. Cuando varias tecnologías resuelven lo mismo, el código aparece en **tabs**, una por tecnología. La tab que elijas queda recordada en todo el sitio.

Marcá cada capítulo como leído con el checkbox del índice o con el botón al final. El progreso queda guardado en este navegador.

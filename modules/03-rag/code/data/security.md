# Security policy for employees

All laptops must use full-disk encryption and lock after 5 minutes of inactivity. Production access requires hardware security keys; SMS codes are not accepted as a second factor.

## Secrets

Secrets are never stored in source code or in chat. They live in the company vault and are rotated every 90 days, or immediately after an employee with access leaves the company.

## Customer data

Engineers may access customer data only to resolve a support ticket, and the ticket id must be written in the access request. Every access is logged and reviewed monthly by the security team.

## Reporting

Suspected phishing or a lost device must be reported to security@northwind.example within one hour.
